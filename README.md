# 💱 Currency Converter (Flutter)

A modern cross-platform currency converter app built using Flutter.  
It converts currencies in real-time using an external API.

---

## 🚀 Features

- 🌍 30+ currencies supported
- 🔄 Real-time conversion
- 🏳️ Country flags UI
- 💻 Desktop support (Windows/macOS/Linux)
- ⚡ Smooth loading animation
- 🧠 Input validation

---

## 🛠️ Tech Stack

- Flutter
- Dart
- HTTP package
- ExcahngeRate API
- window_manager
- country_flags

---

## ⚙️ Installation

```bash
git clone https://github.com/your-username/currency-converter.git
cd currency-converter
flutter pub get
flutter run
```
